## Portafolio · Marilud Uribe Prada

Portafolio personal de Marilud Uribe Prada, desarrolladora junior en formación. Sitio web estático de una sola página, responsive, construido con HTML, CSS y JavaScript puro.

## Descripción

El sitio presenta mi perfil profesional en formación: quién soy, mis habilidades técnicas, proyectos académicos desarrollados en Campuslands, mi formación y datos de contacto.

## Secciones

- **Inicio** — Presentación y foto de perfil.
- **Sobre mí** — Perfil profesional y enfoque de trabajo.
- **Habilidades** — Desarrollo, datos, automatización y competencias blandas.
- **Proyectos** — EcoMarket, TutorBot, proyectos de fundamentos y Eventix.
- **Formación** — Programación de Software en Campuslands, Cúcuta.
- **Contacto** — Enlace a GitHub.

## Tecnologías

- HTML5 semántico
- CSS3 (variables/design tokens, Grid, Flexbox, media queries, animaciones)
- JavaScript vanilla (menú móvil, scroll-spy con `IntersectionObserver`, botón "volver arriba")
- Google Fonts: Space Mono y Press Start 2P

Cómo verlo localmente

1. Cloná el repositorio.
2. Abrí `index.html` en tu navegador (o usá la extensión Live Server de VS Code).
